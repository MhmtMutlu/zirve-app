Short description

Zirve is a free logic puzzle game for iPhone and iPad. You climb a tower where every floor is a short, timed puzzle from 11 types, from color sort and pipes to arrows and sliding blocks. There is a daily tower, weekly leagues and a calm mode with no timer, and no forced ads.

Longer description

Zirve turns short logic puzzles into a climb. Every floor of the tower is one puzzle with a timer: solve it to go up, collect up to three stars and reach a camp every ten floors. Four games are open from the first floor and a new one joins at each camp, until all 11 are in the mix: color match, path draw, block fit, memory, flow, pipe turn, color sort, arrows, gates, lookouts and lights.

Every board is generated and solved by the computer before it is shown, so no puzzle is unsolvable. The daily tower gives everyone the same ten floors each day, with three attempts. Weekly leagues put players into groups of 30, and monthly seasons add a reward path, outfits and tower themes.

Zirve is made by mm-apps, an independent developer in Türkiye, and is available in 17 languages. It shows no forced ads: an ad plays only when a player asks for a reward. Time assist with 1.5× or unlimited time, VoiceOver support and a shape for every colour make it playable for more people.

The puzzles

  • Color match: sliding tile-matching puzzle
  • Path draw: one-line path puzzle
  • Block fit: block fitting puzzle
  • Memory: card matching memory game
  • Flow: connect the dots puzzle
  • Pipe turn: pipe rotation puzzle
  • Color sort: color sort puzzle with tubes
  • Arrows: arrow escape puzzle
  • Gates: sliding block puzzle
  • Lookouts: Star Battle style placement puzzle
  • Lights: light every square puzzle
