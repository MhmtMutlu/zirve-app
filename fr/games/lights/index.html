Lumières : casse-tête pour allumer toutes les cases

Lumières est le dernier jeu à se débloquer et le plus mathématique : toucher une case l'inverse, ainsi que ses quatre voisines ; ce qui est allumé s'éteint, ce qui est éteint s'allume. L'étage est réussi quand toutes les cases sont allumées.

Comment jouer

Allume toutes les cases.

  1. Touche une case : elle et ses voisines du haut, du bas, de gauche et de droite (un +) s'inversent. Les sombres s'allument, les allumées s'éteignent.
  2. Garde le doigt appuyé pour voir quelles cases vont s'inverser ; les diagonales ne changent pas.

Plus haut

  • D'un plateau 3×3 à 5×5
  • De 3 à 10 touches pour résoudre
  • L'ordre compte : réfléchis d'abord, puis touche

Astuces

  • L'ordre des touches n'a pas d'importance, et deux touches sur la même case s'annulent. Chaque case demande au plus une touche.
  • Avance ligne par ligne : touche la case située sous chaque case sombre de la ligne du dessus. Les cases sombres descendent jusqu'à ce qu'il ne reste que la dernière ligne.
  • Le motif restant sur la dernière ligne t'indique quelles cases de la première ligne toucher. Touche-les et redescends ligne par ligne.
  • Une touche dans un coin change trois cases, sur un bord quatre, au milieu cinq. Les coins sont utiles pour les petites retouches.

Où le trouver dans la tour

Le jeu Lumières se débloque à l'étage 71, juste après le camp 70, et cet étage propose toujours Lumières. Ensuite, il revient mêlé aux autres jeux et se corse à mesure que tu grimpes.

En mode zen, tu peux jouer à tous les jeux débloqués sans chrono et sans dépenser de vies. Ce mode ne fait pas progresser dans la tour : il sert à s'entraîner.

Comment s'appelle ce type d'énigme

C'est une version du casse-tête connu sous le nom de lights out (« éteindre les lumières »), d'après un jeu électronique de poche des années 1990. Dans Zirve, le but est inversé : allumer toutes les cases.
