สรุป

  • เราไม่ถามว่าคุณเป็นใคร คุณไม่ต้องให้ชื่อ อีเมล เบอร์โทรศัพท์ ที่อยู่ เลขประจำตัว หรือวันเกิดกับเราเพื่อเล่นเกม เราไม่เข้าถึงตำแหน่งที่ตั้ง รายชื่อติดต่อ รูปภาพ กล้อง หรือไมโครโฟนของคุณ เราไม่เก็บตัวระบุโฆษณาของ Apple (IDFA) เอง Google ซึ่งเป็นผู้แสดงโฆษณา อาจใช้ IDFA ได้ก็ต่อเมื่อคุณแตะ “อนุญาต” ในการขออนุญาตติดตามของ iOS เท่านั้น (โฆษณา)
  • ผู้เล่นถูกจัดเก็บด้วย ID แบบสุ่ม เมื่อเปิดแอปครั้งแรก ระบบจะสร้างบัญชีแขกที่มี ID แบบสุ่มให้คุณ ID นั้นและข้อมูลเกมที่ผูกกับ ID ไม่มีชื่อของคุณ แต่ในทางกฎหมายยังนับเป็นข้อมูลส่วนบุคคล (ข้อมูลแฝง) นโยบายนี้อธิบายถึงข้อมูลดังกล่าว
  • เราประมวลผลเฉพาะสิ่งที่เกมจำเป็นต้องใช้: ความคืบหน้า ผลการเล่น เพชร ลีกและเพื่อน การซื้อ และสถิติการใช้งานเพื่อพัฒนาเกม
  • เราเก็บข้อมูลไว้ไม่นาน ข้อมูลแต่ละประเภทจะถูกเก็บไว้เพียงเท่าที่วัตถุประสงค์ของข้อมูลนั้นจำเป็น (การเก็บรักษา) เราไม่บันทึกที่อยู่ IP ของคุณ: ที่อยู่ IP ถูกใช้เฉพาะในขณะนั้นระหว่างการเชื่อมต่อ เพื่อจำกัดอัตราคำขอ (rate limiting) ป้องกันการโจมตี และไม่ถูกเขียนลงทั้งฐานข้อมูลและบันทึกของเซิร์ฟเวอร์ของเรา
  • เราไม่ขายข้อมูลของคุณ เราจะไม่ใช้ข้อมูลเกมหรือสถิติการใช้งานเพื่อกำหนดเป้าหมายโฆษณาหรือแบ่งปันข้อมูลเหล่านั้นเลย และเราไม่ใช้เครื่องมือวิเคราะห์หรือเครื่องมือรายงานข้อขัดข้องของบุคคลที่สาม
  • โฆษณาแบบปรับให้เหมาะกับคุณจะแสดงเฉพาะเมื่อคุณอนุญาต โฆษณาจะแสดงเฉพาะเมื่อคุณขอดูเท่านั้น แอปจะขออนุญาตติดตามของ iOS เพียงครั้งเดียว Google อาจแสดงโฆษณาแบบปรับให้เหมาะกับคุณและใช้ IDFA ได้ก็ต่อเมื่อคุณแตะ “อนุญาต” (และในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ ต้องให้ความยินยอมในแบบฟอร์มของ Google ด้วย) มิฉะนั้นโฆษณาจะไม่ถูกปรับให้เหมาะกับคุณ คุณเปลี่ยนการตัดสินใจได้ใน การตั้งค่า iOS → ความเป็นส่วนตัวและความปลอดภัย → การติดตาม
  • ในเขตเศรษฐกิจยุโรป เราจะเก็บสถิติการใช้งานเฉพาะเมื่อคุณอนุญาต ในพื้นที่อื่น คุณปิดได้ทุกเมื่อที่ โปรไฟล์ → การตั้งค่า → สถิติการใช้งาน ซึ่งจะลบประวัติสถิติด้วย
  • คุณดาวน์โหลดสำเนาข้อมูลของคุณและลบบัญชีได้ในแอป

1. ข้อมูลที่เราประมวลผล

ประเภทตัวอย่างเมื่อใด
บัญชีID ผู้ใช้แบบสุ่ม หากคุณลงชื่อเข้าใช้ด้วย Apple จะมี ID ผู้ใช้ที่ Apple สร้างขึ้นสำหรับบัญชีนักพัฒนาของเราเท่านั้น: เราไม่ขอชื่อหรืออีเมลของคุณจาก Apple และหาก Apple ส่งมาให้อยู่ดี เราจะลบทิ้งโดยไม่เก็บไว้ Apple เองสามารถจับคู่ ID นี้กับบัญชี Apple ของคุณได้เมื่อเปิดแอปครั้งแรก; เมื่อลงชื่อเข้าใช้ด้วย Apple
โปรไฟล์ชื่อที่แสดง (เราแนะนำให้ใช้ชื่อเล่น; ไม่รับชื่อที่มีอีเมล เบอร์โทรศัพท์ หรือที่อยู่เว็บไซต์; เปลี่ยนได้ทุกเมื่อ) ชุด ธีมหอคอย และกรอบที่คุณเลือก โค้ดเชิญของคุณระหว่างที่คุณเล่น
ความคืบหน้าในเกมชั้นปัจจุบัน สถิติสูงสุดและเวลาที่ทำได้ ความคืบหน้าของแคมป์และหีบ; ผลของแต่ละชั้น (ประเภทปริศนา ดาว เวลาที่เหลือ เล่นต่อหรือไม่ เวลาที่เล่น); บันทึกชั้นที่หมดเวลา; สตรีครายวัน; แต้มซีซั่นและรางวัลที่รับแล้ว; รอบและเวลาในหอคอยประจำวันหลังจบแต่ละชั้นและเมื่อเปิดแอป
เศรษฐกิจในเกมยอดเพชรคงเหลือและความเคลื่อนไหว (เหตุผลที่ได้รับ/ใช้) คลังไอเทมของคุณ (คำใบ้ เวลาเพิ่ม ตัวป้องกันสตรีค)เมื่อคุณได้รับและใช้
สังคมกลุ่มลีกประจำสัปดาห์และอันดับของคุณ การเชื่อมต่อกับเพื่อน โค้ดเชิญที่คุณใช้ บันทึกการแจ้งเตือน “สะกิด” และ “แซงคุณแล้ว” (ใคร ถึงใคร เมื่อใด); กระดานที่คุณแก้ในโหมดผ่อนคลาย (ประเภทปริศนา หมายเลขกระดาน เมื่อใดและใช้เวลานานเท่าใด); ผู้เล่นที่คุณรายงานหรือบล็อก; รางวัลที่คุณได้รับเมื่อจบสัปดาห์ลีกใน 3 อันดับแรก (สัปดาห์ ลีก อันดับ แต้มซีซั่นโบนัส เวลาที่กรอบลีกจะถูกถอดออก)เมื่อถูกจัดเข้าลีก; เมื่อเพิ่มเพื่อน
การแจ้งเตือนโทเค็นพุชของอุปกรณ์คุณ (Apple Push Notification service) โทเค็นจะถูกเก็บเฉพาะในขณะที่คุณอนุญาตการแจ้งเตือน และจะถูกลบออกจากเซิร์ฟเวอร์ของเราเมื่อคุณปิดการแจ้งเตือน หรือไม่ได้เปิดแอปเป็นเวลา 60 วันเมื่อคุณอนุญาตการแจ้งเตือน
การซื้อID ธุรกรรม ผลิตภัณฑ์ ราคา วันที่ ประเทศของร้านค้า และสกุลเงินของการซื้อภายในแอป ข้อมูลบัตรของคุณจะไม่มาถึงเราเลย Apple เป็นผู้รับชำระเงินเมื่อคุณซื้อ
สถิติการใช้งานเวลาที่เซสชันเริ่มและสิ้นสุด หน้าจอที่คุณเปิด ขั้นตอนการแนะนำเริ่มต้น การออกจากหรือเล่นชั้นต่อ การโต้ตอบกับโฆษณาและร้านค้า (เฉพาะผลลัพธ์ ไม่มีรายละเอียดการชำระเงิน) การเปลี่ยนการตั้งค่า; รุ่นอุปกรณ์ เวอร์ชัน iOS เวอร์ชันแอป ภาษา และประเทศของ App Store เราไม่เก็บที่อยู่ IP ตัวระบุโฆษณา หรือตัวระบุอุปกรณ์ของคุณ ดูสถิติการใช้งานระหว่างที่คุณเล่น (ในเขตเศรษฐกิจยุโรปเฉพาะเมื่อคุณยินยอม)
ข้อมูลวินิจฉัยรายงานทางเทคนิคที่ iOS สร้างขึ้น (MetricKit) เมื่อแอปขัดข้องหรือค้าง: call stack ประเภทข้อผิดพลาด รุ่นอุปกรณ์ เวอร์ชัน iOS และเวอร์ชันแอป ไม่มีเนื้อหาในเกม ชื่อ หรือข้อมูลติดต่อ รายงานนี้ผูกกับ ID บัญชีของคุณเมื่อเปิดแอปครั้งถัดไป
โฆษณาเมื่อคุณเลือกดูโฆษณาเพื่อรับรางวัล Google AdMob จะประมวลผลข้อมูลอุปกรณ์และแอป ที่อยู่ IP การโต้ตอบกับโฆษณา (ในเขตเศรษฐกิจยุโรป/สหราชอาณาจักร/สวิตเซอร์แลนด์) ตัวเลือกความยินยอม และตัวระบุโฆษณาของ Apple (IDFA) เฉพาะเมื่อคุณแตะ “อนุญาต” ในการขออนุญาตติดตามของ iOS คำตอบของคุณต่อการขออนุญาตติดตามถูกเก็บไว้โดย iOS ในอุปกรณ์ของคุณ เพื่อยืนยันรางวัล เราแนบตั๋วแบบสุ่มที่ใช้ได้ครั้งเดียวไปกับโฆษณา ID บัญชีของคุณจะไม่ถูกส่งไปยัง Google ดูโฆษณาเมื่อโฆษณาโหลดและเล่น
ข้อมูลทางเทคนิคและความปลอดภัยเวอร์ชันแอป; ส่วนสาธารณะของกุญแจที่สร้างขึ้นในอุปกรณ์ของคุณเพื่อยืนยันว่าแอปเป็น Zirve ของแท้ (Apple App Attest; กุญแจส่วนตัวจะไม่ออกจากอุปกรณ์ของคุณเลย); สัญญาณการโกงและการใช้งานในทางที่ผิด เราไม่บันทึกที่อยู่ IP ของคุณหรือรายละเอียดอุปกรณ์/เบราว์เซอร์: ที่อยู่ IP ของคุณถูกใช้เฉพาะในขณะนั้นระหว่างการเชื่อมต่อ เพื่อจำกัดอัตราคำขอ (rate limiting) ไม่ถูกเขียนลงฐานข้อมูลหรือบันทึกของเซิร์ฟเวอร์ของเรา และจะถูกลบออกจากเซสชันการลงชื่อเข้าใช้ทันทีที่ถูกเขียนลงไป บันทึกทางเทคนิคของเซิร์ฟเวอร์เรา (เพื่อความปลอดภัยและการแก้ไขข้อบกพร่อง) เก็บเวลาของคำขอและรายละเอียดข้อผิดพลาดไว้ไม่เกิน 7 วันทุกครั้งที่เชื่อมต่อกับเซิร์ฟเวอร์
อีเมลขอความช่วยเหลือหากคุณส่งอีเมลถึงเรา: ที่อยู่อีเมลของคุณ ข้อความของคุณ และโค้ดช่วยเหลือที่คุณแนบมา (ถ้ามี) ใช้เพื่อตอบคำขอของคุณและเก็บบันทึกผลลัพธ์ของคำขอเท่านั้นเมื่อคุณเขียนถึงเรา

ความคืบหน้าและการตั้งค่าของคุณยังถูกเก็บไว้ในอุปกรณ์ของคุณด้วย เพื่อให้คุณเล่นแบบออฟไลน์ได้ การ์ดแชร์ถูกสร้างขึ้นในอุปกรณ์ของคุณและจะไม่ถูกส่งมาให้เรา เว้นแต่คุณจะแชร์เอง ความคืบหน้าในโหมดผ่อนคลายของคุณอยู่ในอุปกรณ์ของคุณ มีเพียงการแก้ปริศนาที่นับในรายชื่อประจำสัปดาห์เท่านั้นที่ถูกส่งไปยังเซิร์ฟเวอร์

2. วัตถุประสงค์และฐานทางกฎหมาย

วัตถุประสงค์ข้อมูลฐานทางกฎหมาย
ให้บริการเกม บันทึกความคืบหน้าของคุณ และย้ายความคืบหน้าระหว่างอุปกรณ์บัญชี โปรไฟล์ ความคืบหน้า เศรษฐกิจในเกมการปฏิบัติตามสัญญา (GDPR Art. 6(1)(b); KVKK Art. 5(2)(c))
ลีก หอคอยประจำวัน ซีซั่น ตารางอันดับ และเพื่อนโปรไฟล์ ความคืบหน้า สังคมการปฏิบัติตามสัญญา
ส่งการแจ้งเตือน (เมื่อเพื่อนสะกิดหรือแซงคุณ)โทเค็นพุช สังคมการปฏิบัติตามสัญญา (ฟีเจอร์ที่คุณเปิดเอง) การแจ้งเตือนจะถูกส่งเฉพาะในขณะที่คุณอนุญาตใน iOS เท่านั้น คุณปิดได้ทุกเมื่อในการตั้งค่า iOS
ยืนยันการซื้อ เพิ่มเพชรและพรีเมียมให้ จัดการการคืนเงินและการบัญชีการซื้อ บัญชีการปฏิบัติตามสัญญา; หน้าที่ตามกฎหมาย (Art. 6(1)(c); KVKK Art. 5(2)(ç))
พัฒนาเกม: ทำความเข้าใจผ่านสถิติภาพรวมว่าชั้นไหนยาก ผู้เล่นหยุดเล่นตรงไหน และฟีเจอร์กับร้านค้าถูกใช้อย่างไรสถิติการใช้งาน ความคืบหน้าในเกม บันทึกการซื้อในเขตเศรษฐกิจยุโรป ความยินยอมของคุณ (GDPR Art. 6(1)(a)); ในสหราชอาณาจักร สวิตเซอร์แลนด์ และที่อื่นๆ ประโยชน์โดยชอบด้วยกฎหมาย (GDPR/UK GDPR Art. 6(1)(f)); ในทูร์เคีย ประโยชน์โดยชอบด้วยกฎหมาย (KVKK Art. 5(2)(f)) สถิติเหล่านี้จะไม่ถูกใช้ตัดสินรางวัล ผลลีก หรือราคาหรือข้อเสนอสำหรับคุณเลย
แก้ไขปัญหาแอปขัดข้องและค้างข้อมูลวินิจฉัยประโยชน์โดยชอบด้วยกฎหมาย (Art. 6(1)(f); KVKK Art. 5(2)(f))
แสดงโฆษณาแบบรับรางวัลเมื่อคุณขอ และยืนยันรางวัลข้อมูลโฆษณาโฆษณาที่ไม่ปรับให้เหมาะกับคุณ: การปฏิบัติตามสัญญา (รางวัลที่คุณขอ) และประโยชน์โดยชอบด้วยกฎหมาย (เกมฟรีที่สนับสนุนด้วยโฆษณา) (GDPR Art. 6(1)(b), (f); KVKK Art. 5(2)(c), (f)) โฆษณาแบบปรับให้เหมาะกับคุณและ IDFA: ความยินยอมของคุณ (GDPR Art. 6(1)(a); ความยินยอมโดยชัดแจ้งตาม KVKK Art. 5(1)) ซึ่งให้โดยการแตะ “อนุญาต” ในการขออนุญาตติดตามของ iOS และในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ รวมถึงในแบบฟอร์มความยินยอมของ Google ด้วย คุณถอนความยินยอมได้ทุกเมื่อ
ป้องกันการโกงและการใช้งานในทางที่ผิด ความปลอดภัย ตรวจสอบชื่อที่ไม่เหมาะสมและการรายงานข้อมูลทางเทคนิคและความปลอดภัย ความคืบหน้า เศรษฐกิจในเกม สังคมประโยชน์โดยชอบด้วยกฎหมาย (Art. 6(1)(f); KVKK Art. 5(2)(f))
ตอบคำขอใช้สิทธิและคำขอความช่วยเหลือ บันทึกการลบอีเมลขอความช่วยเหลือ บัญชีหน้าที่ตามกฎหมาย; ประโยชน์โดยชอบด้วยกฎหมาย

เราไม่ใช้ข้อมูลของคุณในการตัดสินใจอัตโนมัติที่อิงการทำโปรไฟล์ หรือเพื่อส่งอีเมลการตลาด สำหรับโฆษณาแบบปรับให้เหมาะกับคุณ Google สร้างโปรไฟล์ตามความสนใจภายใต้ความรับผิดชอบของ Google เอง และเฉพาะเมื่อคุณอนุญาตเท่านั้น การตรวจสอบป้องกันการโกงอาจไม่นับผลการเล่นบางครั้ง หากคุณไม่เห็นด้วย คุณเขียนถึงเราได้

3. สถิติการใช้งาน

  • สถิติถูกเก็บไว้ในฐานข้อมูลของเราเองเท่านั้น (บนเซิร์ฟเวอร์ของเราในทูร์เคีย) บันทึกที่ผูกกับบัญชีของคุณจะถูกลบหลังจาก 90 วัน ในระยะยาวจะเหลือเพียงยอดรวมรายวันที่ไม่ผูกกับบุคคลใด สถิติเหล่านี้จะไม่ถูกแบ่งปันให้บริษัทอื่น จะไม่ถูกใช้เพื่อโฆษณาหรือการติดตาม และจะไม่ถูกใช้ติดตามคุณข้ามแอปหรือเว็บไซต์อื่นเลย
  • เขตเศรษฐกิจยุโรป (ประเทศในสหภาพยุโรป ไอซ์แลนด์ ลิกเตนสไตน์ นอร์เวย์): หลังจากบทแนะนำ เราจะถามหนึ่งครั้งว่า “แชร์ / ไม่แชร์” จะไม่มีการบันทึกใดๆ จนกว่าคุณจะตอบ และจะไม่บันทึกเลยหากคุณเลือก “ไม่แชร์” เราระบุภูมิภาคของคุณจากประเทศของ App Store และจากข้อมูลที่แบบฟอร์มความยินยอมด้านโฆษณารายงาน หากระบุไม่ได้ เราจะถือว่าคุณอยู่ในภูมิภาคที่เราต้องถาม
  • ประเทศอื่นๆ (ทูร์เคีย สหราชอาณาจักร สวิตเซอร์แลนด์ และที่อื่นๆ): สถิติเปิดอยู่โดยค่าเริ่มต้น เราแจ้งให้คุณทราบด้วยข้อความหนึ่งบรรทัดเมื่อเปิดแอปครั้งแรก
  • ไม่ว่าคุณจะอยู่ที่ใด คุณปิดหรือเปิดได้ที่ โปรไฟล์ → การตั้งค่า → สถิติการใช้งาน การปิดจะหยุดการบันทึกและลบสถิติในอดีตของคุณออกจากเซิร์ฟเวอร์ของเรา เราเก็บบันทึกตัวเลือกของคุณ (เมื่อใด ข้อความฉบับใด) ไว้ตราบเท่าที่บัญชีของคุณยังอยู่ เพื่อพิสูจน์ความยินยอม

4. สิ่งที่ผู้เล่นคนอื่นมองเห็น

ในตารางอันดับ ผู้เล่นคนอื่นจะเห็นชื่อที่แสดง ชุด ธีมหอคอย และกรอบของคุณ (กรอบลีกที่คุณได้รับในสัปดาห์ลีก หรือกรอบที่คุณเลือก) นอกจากนี้:

  • กลุ่มลีกของคุณ: จำนวนชั้นที่ปีนได้ในสัปดาห์นี้และอันดับของคุณ
  • เพื่อนของคุณ: ชั้นสถิติสูงสุด ลีก และเวลาที่คุณเล่นครั้งล่าสุด
  • ตารางอันดับหอคอยประจำวัน: จำนวนชั้นที่ผ่านและเวลาของคุณ
  • รายชื่อโหมดผ่อนคลายประจำสัปดาห์: จำนวนปริศนาที่คุณไขในโหมดผ่อนคลายสัปดาห์นี้
  • สุดยอดนักปีน (“Zirvedekiler”) 20 อันดับแรกตลอดกาลตามชั้นสูงสุดของหอคอย: ชั้นสถิติสูงสุดและอันดับของคุณ

อย่าใช้ชื่อจริงเป็นชื่อที่แสดง ตั้งชื่อเล่นแทน หน้าจอตั้งชื่อจะเตือนคุณ ชื่อที่ดูเหมือนอีเมล เบอร์โทรศัพท์ หรือที่อยู่เว็บไซต์จะไม่ได้รับการยอมรับ ชื่อที่ไม่เหมาะสมอาจถูกเปลี่ยน คุณรายงานหรือบล็อกผู้เล่นได้ เมื่อคุณแชร์ชื่อที่แสดงหรือการ์ดแชร์ด้วยตัวเอง สิ่งเหล่านั้นจะอยู่ภายใต้การควบคุมของบุคคลและแพลตฟอร์มที่คุณแชร์ให้

5. ผู้ให้บริการและการโอนข้อมูลไปต่างประเทศ

เราแบ่งปันข้อมูลเฉพาะกับผู้ให้บริการที่จำเป็นต่อการดำเนินบริการ และเฉพาะเท่าที่บริการของผู้ให้บริการนั้นจำเป็นต้องใช้:

  • Güzel Hosting (GNET İnternet Telekomünikasyon A.Ş., ทูร์เคีย) — บริการเซิร์ฟเวอร์เสมือนที่เซิร์ฟเวอร์และข้อมูลสำรองของเราทำงานอยู่ ฐานข้อมูล การยืนยันตัวตน ฟังก์ชันของเซิร์ฟเวอร์ สถิติการใช้งาน และข้อมูลวินิจฉัย ทำงานบนเซิร์ฟเวอร์นี้ด้วยซอฟต์แวร์ที่เราดูแลเอง (Supabase แบบโอเพนซอร์ส) ข้อมูลสำรองถูกเข้ารหัสบนเซิร์ฟเวอร์และเก็บไว้ 30 วันในพื้นที่จัดเก็บข้อมูลสำรองของ Güzel Hosting ในทูร์เคีย
  • RevenueCat Inc. (สหรัฐอเมริกา) — การยืนยันและการจัดการการซื้อภายในแอป เฉพาะเมื่อคุณซื้อหรือแตะ “กู้คืนการซื้อ” (หรือมีการซื้อใน App Store ของคุณที่รอดำเนินการให้เสร็จ) RevenueCat จะได้รับ ID บัญชีแบบสุ่มของคุณ รายละเอียดการซื้อของคุณ และข้อมูลอุปกรณ์ที่ซอฟต์แวร์ของ RevenueCat เก็บรวบรวม (รุ่นอุปกรณ์ เวอร์ชัน iOS ภาษา ประเทศของ App Store ตัวระบุอุปกรณ์ที่ Apple ให้กับแอปนี้) สำหรับผู้เล่นที่ไม่ได้ซื้อ จะไม่มีข้อมูลใดถูกส่งไปยัง RevenueCat ราคาในร้านค้าถูกอ่านจาก Apple โดยตรง RevenueCat ประมวลผลข้อมูลเหล่านี้ในนามของเราภายใต้ข้อกำหนดการให้บริการและภาคผนวกการประมวลผลข้อมูล (data processing addendum) ที่ RevenueCat เผยแพร่ ความเป็นส่วนตัว
  • Google LLC / Google Ireland Ltd. — โฆษณา AdMob และการจัดการความยินยอม (User Messaging Platform) ประมวลผลข้อมูลภายใต้นโยบายของตนเองในฐานะผู้ควบคุมข้อมูลอิสระ Google ใช้ IDFA และโฆษณาแบบปรับให้เหมาะกับคุณเฉพาะเมื่อคุณอนุญาตเท่านั้น ความเป็นส่วนตัว
  • Apple Inc. — การลงชื่อเข้าใช้ด้วย Apple การชำระเงินใน App Store การส่งการแจ้งเตือน การยืนยันแอป (App Attest) และ Game Center (หากคุณลงชื่อเข้าใช้ Game Center ชั้นสถิติสูงสุด ผลหอคอยประจำวัน และความสำเร็จของคุณจะถูกส่งไปยัง Game Center); เป็นผู้ควบคุมข้อมูลอิสระ ความเป็นส่วนตัว
  • GitHub Inc. (สหรัฐอเมริกา) — โฮสต์เว็บไซต์นี้ GitHub ประมวลผลบันทึกการเข้าถึงที่มีที่อยู่ IP ภายใต้นโยบายของตนเอง เว็บไซต์นี้ไม่ใช้คุกกี้
  • อีเมล: ที่อยู่อีเมลช่วยเหลือของเราใช้บริการอีเมลธุรกิจของ Güzel Hosting อีเมลที่คุณส่งถึงเราจะถูกเก็บไว้บนเซิร์ฟเวอร์ของ Güzel Hosting ในทูร์เคีย อีเมลตอบกลับของเราถูกส่งผ่าน MailChannels Corporation (แคนาดา; เซิร์ฟเวอร์ในอเมริกาเหนือ) ซึ่งเป็นผู้ให้บริการส่งต่ออีเมลของ Güzel Hosting: อีเมลตอบกลับและที่อยู่อีเมลของคุณจะผ่านเซิร์ฟเวอร์ของผู้ให้บริการนี้ระหว่างการส่งและไม่ถูกเก็บไว้ที่นั่น

การโอนข้อมูลไปต่างประเทศ: เซิร์ฟเวอร์ของเราอยู่ในทูร์เคีย ข้อมูลที่ส่งไปยัง RevenueCat (สหรัฐอเมริกา) เพื่อยืนยันการซื้อเมื่อคุณซื้อ ไปยัง Google เมื่อคุณเลือกดูโฆษณาเพื่อรับรางวัล และไปยัง Apple เมื่อคุณใช้บริการของ Apple จะถูกโอนไปต่างประเทศ อีเมลที่คุณส่งถึงเราถูกเก็บไว้ในทูร์เคีย อีเมลตอบกลับของเราถึงคุณจะผ่านเซิร์ฟเวอร์ของ MailChannels (แคนาดา) ระหว่างการส่ง ข้อมูลที่ส่งไปยัง Google และ Apple ถูกประมวลผลเป็นส่วนหนึ่งของการที่คุณเลือกใช้บริการเหล่านั้น และความสัมพันธ์ของคุณเองกับบริษัทเหล่านั้น เราอาจเปิดเผยข้อมูลต่อหน่วยงานที่มีอำนาจหน้าที่เมื่อกฎหมายกำหนดด้วย คุณเขียนถึงเราเพื่อขอข้อมูลเพิ่มเติมเกี่ยวกับการโอนข้อมูลเหล่านี้ได้

ผู้เล่นในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์: ผู้ควบคุมข้อมูลและเซิร์ฟเวอร์ของเราอยู่ในทูร์เคีย ข้อมูลของคุณจึงถูกประมวลผลและจัดเก็บในทูร์เคีย ไม่มีคำตัดสินว่าด้วยความเพียงพอ (adequacy decision) ของสหภาพยุโรปสำหรับทูร์เคีย ระยะเวลาการเก็บรักษา มาตรการรักษาความปลอดภัย และสิทธิในนโยบายนี้ใช้กับคุณเช่นกัน

การเปลี่ยนเซิร์ฟเวอร์: จนถึงวันที่ 30 ตุลาคม 2026 ข้อมูลของคุณถูกโฮสต์อยู่บนโครงสร้างพื้นฐานของ Supabase Pte. Ltd. ในแฟรงก์เฟิร์ต ประเทศเยอรมนี โปรเจกต์นั้นถูกลบไปเมื่อวันที่ 30 ตุลาคม 2026 ที่อยู่อีเมลช่วยเหลือของเราก็อยู่บนบริการ Gmail ของ Google จนถึงวันที่ 30 ตุลาคม 2026 เช่นกัน อีเมลที่คุณส่งหลังจากวันนั้นจะถูกเก็บไว้ที่ Güzel Hosting ในทูร์เคีย

6. โฆษณา

โฆษณาใน Zirve จะแสดงเฉพาะเมื่อคุณขอดูเท่านั้น: เมื่อคุณแตะ “ดูโฆษณา” เพื่อรับชีวิต เล่นต่อหลังหมดเวลา หรือเพิ่มรางวัล ไม่มีโฆษณาใดขัดจังหวะการเล่น และโฆษณาถูกจำกัดเฉพาะเนื้อหาที่เหมาะสำหรับผู้ชมทั่วไป

  • โฆษณาแสดงโดย Google AdMob Google ประมวลผลข้อมูลอุปกรณ์และแอป ที่อยู่ IP ของคุณ (รวมถึงตำแหน่งโดยประมาณที่ได้จากที่อยู่ IP) และการโต้ตอบกับโฆษณา เพื่อแสดงและวัดผลโฆษณา และเพื่อป้องกันการฉ้อโกง เราไม่เก็บตำแหน่งที่ตั้งของคุณ
  • ในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ แบบฟอร์มความยินยอมของ Google (IAB TCF) จะแสดงหลังหน้าต้อนรับเมื่อเปิดแอปครั้งแรก คุณเปลี่ยนตัวเลือกได้ทุกเมื่อในตัวเลือกความเป็นส่วนตัวของแอป (โปรไฟล์ → การตั้งค่า) แบบฟอร์มนี้ไม่ใช่ความยินยอมต่อสถิติการใช้งานของเรา เราขอความยินยอมสำหรับสถิติแยกต่างหาก
  • การขออนุญาตติดตาม (App Tracking Transparency): หลังจากนั้น iOS จะแสดงข้อความ “อนุญาตให้แอปขอติดตาม” เพียงครั้งเดียว (และจะไม่แสดงเลยหากคุณปฏิเสธแบบฟอร์มของ Google) Google อาจแสดงโฆษณาแบบปรับให้เหมาะกับคุณและใช้ตัวระบุโฆษณาของ Apple (IDFA) ได้ก็ต่อเมื่อคุณแตะ “อนุญาต” และในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ ได้ให้ความยินยอมในแบบฟอร์มของ Google ด้วย
  • มิฉะนั้นโฆษณาจะไม่ถูกปรับให้เหมาะกับคุณ และ IDFA จะไม่ถูกใช้เลย Google ยังคงใช้ข้อมูลข้างต้นเพื่อแสดง วัดผล และป้องกันการฉ้อโกงในโฆษณาที่ไม่ปรับให้เหมาะกับคุณ ซึ่งอาจถูกเลือกตามตำแหน่งโดยประมาณ
  • ผู้เล่นที่อายุไม่ถึงเกณฑ์: หากข้อมูลอายุของ Apple แสดงว่าคุณอายุต่ำกว่าเกณฑ์อายุที่ให้ความยินยอมได้ในประเทศของคุณ จะไม่มีการถามเรื่องการติดตามเลย โฆษณาจะไม่ถูกปรับให้เหมาะกับคุณเลย และ Google จะได้รับแจ้งว่าคำขอนั้นมาจากผู้ใช้ที่อายุต่ำกว่าเกณฑ์อายุที่ให้ความยินยอมได้
  • คุณเปลี่ยนการตัดสินใจได้ทุกเมื่อใน การตั้งค่า iOS → ความเป็นส่วนตัวและความปลอดภัย → การติดตาม หากคุณปิด โฆษณาหลังจากนั้นจะไม่ถูกปรับให้เหมาะกับคุณ
  • สถิติการใช้งานของเราเองแยกจากกัน: จะไม่ถูกใช้เพื่อโฆษณาหรือการติดตาม จะไม่ถูกแบ่งปันให้ Google หรือใครอื่น และไม่มีตัวระบุโฆษณา
  • วิธีที่ Google ใช้ข้อมูล: policies.google.com/technologies/partner-sites

7. การเก็บรักษาและการลบ

  • เราเก็บข้อมูลเกมไว้ตราบเท่าที่บัญชีของคุณยังอยู่ บัญชีแขกที่ไม่เคยลงชื่อเข้าใช้ด้วย Apple และไม่เคยซื้ออะไรเลย จะถูกลบโดยอัตโนมัติพร้อมข้อมูลเกมทั้งหมด หลังจากไม่มีการใช้งานใดๆ เป็นเวลา 12 เดือน (แอปไม่ได้เชื่อมต่อกับเซิร์ฟเวอร์ของเราเลย)
  • สถิติการใช้งานถูกเก็บไว้ไม่เกิน 90 วัน และจะถูกลบทันทีเมื่อคุณปิดสถิติหรือลบบัญชี ยอดรวมรายวันที่ไม่ผูกกับบุคคลใด (เช่น จำนวนผู้เล่นต่อวัน) จะคงอยู่เป็นเวลา 13 เดือน
  • รายงานวินิจฉัยถูกเก็บไว้ 30 วัน บันทึกการแจ้งเตือน 30 วัน ตั๋วรางวัลโฆษณา 30 วัน บันทึกชั้นที่หมดเวลา 90 วัน การแก้ปริศนาในโหมดผ่อนคลาย 30 วัน (จำนวนรายสัปดาห์ 90 วัน) รางวัลสัปดาห์ลีกจนถึง 30 วันหลังจากกรอบลีกถูกถอดออก กุญแจยืนยันแอปจะถูกลบหลังจากไม่มีการใช้งาน 12 เดือน
  • โทเค็นพุชของคุณจะถูกลบหากคุณไม่ได้เปิดแอปเป็นเวลา 60 วัน เซสชันการลงชื่อเข้าใช้ไม่เก็บที่อยู่ IP หรือรายละเอียดอุปกรณ์ บันทึกความปลอดภัยของการลงชื่อเข้าใช้ถูกเก็บไว้โดยไม่มีที่อยู่ IP และอีเมล เป็นเวลาไม่เกิน 1 ชั่วโมง
  • บันทึกทางเทคนิคของเซิร์ฟเวอร์เรา (เวลาของคำขอ รายละเอียดข้อผิดพลาด; ไม่มีที่อยู่ IP) ถูกเก็บไว้ไม่เกิน 7 วัน และถูกลบโดยอัตโนมัติ ที่อยู่ต้นทางของความพยายามเชื่อมต่อกับเซิร์ฟเวอร์โดยไม่ได้รับอนุญาต (บันทึกไฟร์วอลล์และบันทึกการเข้าถึงเพื่อการดูแลระบบ) ก็ถูกเก็บไว้ไม่เกิน 7 วันเช่นกัน ข้อมูลเหล่านี้ไม่ใช่ทราฟฟิกของเกม
  • เมื่อคุณลบบัญชี (โปรไฟล์ → การตั้งค่า → บัญชี → ลบบัญชี) บัญชีของคุณและข้อมูลเกมที่ผูกกับบัญชีจะถูกลบทันที และจะหายไปจากข้อมูลสำรองที่เข้ารหัสภายใน 30 วัน ข้อยกเว้น: เพื่อตรวจสอบการโกงและการคืนเงิน ความเคลื่อนไหวของเพชรและสัญญาณการโกงจะถูกเก็บไว้ไม่เกิน 12 เดือน และเหตุการณ์การซื้อ (ผลิตภัณฑ์ วันที่ ประเทศ สกุลเงิน ราคา ID ธุรกรรม) ไม่เกิน 24 เดือน โดยตัดการเชื่อมโยงกับบัญชีของคุณออก จากนั้นจะถูกลบหรือทำให้เป็นข้อมูลนิรนาม เราขอให้ RevenueCat ลบบันทึกลูกค้า และหากคุณลงชื่อเข้าใช้ด้วย Apple เราจะขอให้ Apple เพิกถอนการอนุญาต “ลงชื่อเข้าใช้ด้วย Apple” ที่ให้ไว้กับแอปนี้ เราบันทึกการลบนั้นเองโดยมีเพียงวันที่และหมายเลขคำขอแบบสุ่ม (ไม่ใช่ ID ของคุณ) เป็นเวลา 3 ปี ดูลบบัญชีของคุณ
  • อีเมลขอความช่วยเหลือจะถูกเก็บไว้หลังจากปิดคำขอแล้วเพียงเท่าที่จำเป็นเพื่อแสดงว่าคำขอได้รับการจัดการอย่างไร จากนั้นจะถูกลบ
  • ใบเสร็จการซื้อในร้านค้าของคุณยังคงอยู่ในบัญชี Apple ของคุณ และบันทึก Game Center ของคุณอยู่กับ Apple
  • การลบแอปจะลบเฉพาะข้อมูลในอุปกรณ์ของคุณ หากต้องการลบบัญชีแขกของคุณบนเซิร์ฟเวอร์ของเรา ให้ใช้ “ลบบัญชี” ในแอปก่อน หรือส่งอีเมลถึงเราพร้อมโค้ดช่วยเหลือที่แสดงในแอป

8. ความปลอดภัย

เราใช้มาตรการทางเทคนิคและเชิงองค์กรที่สมเหตุสมผลเพื่อปกป้องข้อมูล: ข้อมูลถูกเข้ารหัสระหว่างการส่งด้วย TLS; ข้อมูลสำรองถูกเข้ารหัสบนเซิร์ฟเวอร์; ในฐานข้อมูล ผู้เล่นแต่ละคนเข้าถึงได้เฉพาะข้อมูลของตนเอง (row-level security); สถิติการใช้งานไม่สามารถเข้าถึงได้โดยตรงจากภายนอก; การดำเนินการที่ละเอียดอ่อน เช่น ยอดคงเหลือและรางวัล เกิดขึ้นบนเซิร์ฟเวอร์เท่านั้น; มีเพียงนักพัฒนาเท่านั้นที่ดูแลเซิร์ฟเวอร์ ข้อมูลในอุปกรณ์ของคุณได้รับการปกป้องโดยระบบความปลอดภัยของอุปกรณ์คุณเอง

ไม่มีระบบใดปลอดภัยอย่างสมบูรณ์ และไม่สามารถรับประกันความปลอดภัยอย่างสมบูรณ์ได้ หากเราทราบว่ามีการละเมิดข้อมูล เราจะดำเนินการเพื่อจำกัดผลกระทบ และแจ้งตามที่กฎหมายกำหนด (ต่อหน่วยงานที่มีอำนาจหน้าที่และต่อคุณ ในกรณีที่กฎหมายกำหนด)

9. เด็ก

Zirve เป็นเกมปริศนาที่ทุกคนเล่นได้ แต่ไม่ได้ออกแบบมาสำหรับเด็กโดยเฉพาะ และไม่อยู่ในหมวดเด็ก (Kids) ของ App Store เราไม่ขอชื่อ อีเมล หรือวันเกิดของคุณ โฆษณาจะแสดงเฉพาะเมื่อขอดูและถูกจำกัดเฉพาะเนื้อหาที่เหมาะสำหรับผู้ชมทั่วไป หากเราทราบว่าเด็กอายุต่ำกว่า 13 ปี (หรืออายุที่สูงกว่านั้นหากประเทศของคุณกำหนด) ได้ให้ข้อมูลส่วนบุคคลแก่เรา เราจะลบบัญชีนั้น พ่อแม่และผู้ปกครองติดต่อเราได้ที่ destek@mm-apps.com

10. สิทธิของคุณ

ภายใต้ GDPR (เขตเศรษฐกิจยุโรป/สหราชอาณาจักร) และกฎหมายท้องถิ่นที่เกี่ยวข้อง (สวิตเซอร์แลนด์) และ KVKK (ทูร์เคีย) คุณมีสิทธิเข้าถึงข้อมูลของคุณและขอรับสำเนา แก้ไขข้อมูล ลบข้อมูล จำกัดหรือคัดค้านการประมวลผล ขอรับข้อมูลในรูปแบบที่โอนย้ายได้ และถอนความยินยอม

สิทธิคัดค้าน: คุณคัดค้านการประมวลผลที่อิงประโยชน์โดยชอบด้วยกฎหมายได้ทุกเมื่อ โดยเฉพาะสถิติการใช้งาน วิธีที่ง่ายที่สุดคือปิด โปรไฟล์ → การตั้งค่า → สถิติการใช้งาน การบันทึกจะหยุดและสถิติในอดีตของคุณจะถูกลบ หากคุณให้ความยินยอมไว้ คุณถอนความยินยอมได้ที่เดียวกัน คุณถอนการอนุญาตสำหรับโฆษณาแบบปรับให้เหมาะกับคุณได้ใน การตั้งค่า iOS → ความเป็นส่วนตัวและความปลอดภัย → การติดตาม และในตัวเลือกความเป็นส่วนตัวของแอป (โปรไฟล์ → การตั้งค่า) การถอนความยินยอมไม่กระทบต่อความชอบด้วยกฎหมายของการประมวลผลก่อนหน้านั้น

วิธียื่นคำขอ: คุณรับสำเนาข้อมูลของคุณได้ทันทีที่ โปรไฟล์ → การตั้งค่า → บัญชี → ดาวน์โหลดข้อมูลของฉัน คุณลบบัญชีได้ในแอปและเปลี่ยนชื่อที่แสดงได้ที่นั่น สำหรับคำขออื่นๆ ไม่ว่าคุณจะอยู่ที่ใด ให้ส่งอีเมลถึงเราโดยตรงที่ destek@mm-apps.com และแนบโค้ดช่วยเหลือที่แสดงในแอป (โปรไฟล์ → การตั้งค่า → บัญชี) โค้ดนี้มองเห็นได้เฉพาะในอุปกรณ์ของคุณ และช่วยให้เรายืนยันได้ว่าคำขอมาจากคุณ เนื่องจากเราไม่เก็บชื่อหรืออีเมล เราอาจไม่สามารถค้นหาบัญชีของคุณด้วยวิธีอื่นได้ เราจะตอบกลับภายใน 30 วันโดยไม่มีค่าใช้จ่าย คุณยังสามารถยื่นเรื่องร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลในพื้นที่ของคุณ หรือในทูร์เคีย ต่อคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (Personal Data Protection Board) ได้
