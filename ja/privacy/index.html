このポリシーは、あなたがZirveモバイルゲーム（iPhoneおよびiPad）とこのウェブサイト（以下「本サービス」）を利用するときに、個人データがどのように処理されるかを説明するものです。

データ管理者：Mehmet Mutlu（トルコを拠点とする個人開発者。以下「Zirve」「私たち」）。連絡先：destek@mm-apps.com。トルコのユーザーはKVKK情報通知（トルコ語）も読むことができます。ゲームの利用ルールは利用規約にあります。このポリシーはあなたへの情報提供を目的としたもので、同意は必要ありません。

概要

  • あなたが誰なのかは尋ねません。プレイするために、名前、メールアドレス、電話番号、住所、身分証番号、生年月日を私たちに伝える必要はありません。位置情報、連絡先、写真、カメラ、マイクにはアクセスしません。Appleの広告識別子（IDFA）を私たち自身が収集することはありません。広告を配信するGoogleがIDFAを使用できるのは、あなたがiOSのトラッキング許可で「許可」をタップした場合だけです（広告）。
  • プレイヤーはランダムなIDで保存されます。初回起動時に、ランダムなIDを持つゲストアカウントがあなたのために作成されます。このIDとそれに紐づくゲームデータにはあなたの名前は含まれませんが、法律上は依然として個人データ（仮名化データ）にあたります。このポリシーはそのデータについて説明しています。
  • 処理するのはゲームに必要なものだけです：進行状況、結果、ジェム、リーグとフレンド、購入、そしてゲームを改善するための利用統計です。
  • データは短期間だけ保存します。各データは、その目的に必要な期間だけ保存されます（保存期間）。IPアドレスは記録しません。IPアドレスは攻撃に対するレート制限のために接続中その場でのみ使用され、データベースにもサーバーログにも書き込まれません。
  • あなたのデータを販売しません。ゲームデータや利用統計を広告ターゲティングに使用したり共有したりすることは一切なく、第三者の分析ツールやクラッシュレポートツールも使用しません。
  • パーソナライズ広告はあなたの許可がある場合だけです。広告は、あなたが求めたときにだけ表示されます。アプリはiOSのトラッキング許可を一度だけ求めます。Googleがパーソナライズ広告を表示しIDFAを使用できるのは、あなたが「許可」をタップした場合（EEA、英国、スイスではGoogleのフォームでも同意した場合）だけです。それ以外の場合、広告はパーソナライズされません。この判断はiOSの「設定」→「プライバシーとセキュリティ」→「トラッキング」でいつでも変更できます。
  • 欧州経済領域（EEA）では、あなたが許可した場合にのみ利用統計を保存します。それ以外の地域では、「プロフィール → 設定 → 利用統計」でいつでもオフにでき、オフにするとその履歴も削除されます。
  • アプリ内で、あなたのデータのコピーをダウンロードしたり、アカウントを削除したりできます。

3. 利用統計

  • 統計は私たち自身のデータベース（トルコにある私たちのサーバー）にのみ保存されます。あなたのアカウントに紐づく記録は90日後に削除され、長期的には誰にも紐づかない日ごとの合計だけが残ります。統計がほかの企業と共有されることも、広告やトラッキングに使われることも、ほかのアプリやウェブサイトをまたいであなたを追跡するために使われることも一切ありません。
  • 欧州経済領域（EU加盟国、アイスランド、リヒテンシュタイン、ノルウェー）：チュートリアルのあとに一度だけ「共有する／共有しない」を尋ねます。あなたが回答するまでは何も記録されず、「共有しない」を選んだ場合も何も記録されません。あなたの地域は、App Storeの国と広告の同意フォームが報告する内容から判断します。判断できない場合は、同意を尋ねる地域にいるものとして扱います。
  • その他の国（トルコ、英国、スイス、その他の地域）：統計は初期設定でオンになっています。初回起動時に、そのことを一行でお知らせします。
  • どの地域でも、「プロフィール → 設定 → 利用統計」でオフ・オンを切り替えられます。オフにすると記録が止まり、過去の統計もサーバーから削除されます。同意を証明するため、あなたの選択の記録（いつ、どのバージョンの文言か）をアカウントが存在する間保存します。

4. ほかのプレイヤーに表示される情報

ランキングでは、ほかのプレイヤーにあなたの表示名、衣装、タワーテーマ、フレーム（リーグの週で獲得したリーグフレーム、またはあなたが選んだフレーム）が表示されます。さらに：

  • あなたのリーグのグループ：今週登った階数とあなたの順位。
  • あなたのフレンド：あなたの最高記録の階、リーグ、最後にプレイした日時。
  • 今日のタワーのランキング：クリアした階数とタイム。
  • のんびりモードの週間リスト：今週のんびりモードで解いたパズルの数。
  • 頂上の20人（「Zirvedekiler」）（タワーの最高到達階による歴代トップ20）：あなたの最高記録の階と順位。

表示名に本名を使わず、ニックネームを選んでください。名前の画面でもそのことをお知らせします。メールアドレス、電話番号、ウェブアドレスのように見える名前は受け付けません。不適切な名前は変更されることがあります。プレイヤーを通報またはブロックすることもできます。あなたが自分で表示名やシェアカードを共有した場合、それらは共有した相手の人やプラットフォームの管理下に入ります。

6. 広告

Zirveの広告はあなたが求めたときにだけ表示されます。ライフをもらう、時間切れのあとに続ける、または報酬を増やすために「広告を見る」をタップしたときです。プレイを中断する広告はなく、広告は一般の利用者向けにふさわしい内容に限られています。

  • 広告はGoogle AdMobが配信します。Googleは、広告の表示と効果測定、不正防止のために、デバイスとアプリの情報、あなたのIPアドレス（それから推定されるおおよその位置を含む）、広告での操作を処理します。私たちがあなたの位置情報を収集することはありません。
  • EEA、英国、スイスでは、初回起動時のウェルカムページのあとにGoogleの同意フォーム（IAB TCF）が表示されます。あなたの選択は、アプリのプライバシーの選択（プロフィール → 設定）でいつでも変更できます。このフォームは私たちの利用統計への同意ではありません。利用統計については別に尋ねます。
  • トラッキング許可（App Tracking Transparency）：そのあと、iOSの「Appからのトラッキング要求を許可」の確認が一度だけ表示されます（Googleのフォームで拒否した場合は表示されません）。Googleがパーソナライズ広告を表示し、Appleの広告識別子（IDFA）を使用できるのは、あなたが「許可」をタップし、かつEEA、英国、スイスではGoogleのフォームでも同意した場合だけです。
  • それ以外の場合、広告はパーソナライズされず、IDFAが使用されることは一切ありません。Googleはそれでも、パーソナライズされない広告の配信、効果測定、不正防止のために上記のデータを使用します。パーソナライズされない広告は、おおよその位置に基づいて選ばれることがあります。
  • 同意年齢未満のプレイヤー：Appleの年齢情報から、あなたがお住まいの国の同意年齢に満たないとわかった場合、トラッキングの確認は一切表示されず、広告がパーソナライズされることもなく、Googleにはそのリクエストが同意年齢に満たないユーザーのものであると伝えられます。
  • この判断はiOSの「設定」→「プライバシーとセキュリティ」→「トラッキング」でいつでも変更できます。オフにすると、それ以降の広告はパーソナライズされません。
  • 私たち自身の利用統計はこれとは別です。広告やトラッキングに使われることも、Googleやほかの誰かと共有されることも一切なく、広告識別子も含みません。
  • Googleによるデータの使用方法：policies.google.com/technologies/partner-sites。

7. 保存期間と削除

  • ゲームデータは、あなたのアカウントが存在する間保存します。Appleで一度もサインインせず、一度も購入していないゲストアカウントは、まったく使われない状態（アプリが私たちのサーバーに一度も接続しない状態）が12か月続くと、すべてのゲームデータとともに自動的に削除されます。
  • 利用統計は最大90日間保存され、あなたがオフにしたときやアカウントを削除したときには直ちに削除されます。誰にも紐づかない日ごとの合計（例：1日あたりのプレイヤー数）は13か月間残ります。
  • 診断レポートは30日間、通知の記録は30日間、広告の報酬チケットは30日間、時間切れになった階の記録は90日間、のんびりモードで解いた盤面の記録は30日間（週ごとの数は90日間）、リーグの週の賞はリーグフレームが外れてから30日後まで保存されます。アプリ確認用の鍵は、12か月間使われないと削除されます。
  • プッシュトークンは、60日間アプリを開かなかった場合に削除されます。UTCとの時差は、リーグの通知をオフにしたとき、またはトークンが削除されたときに削除されます。サインインセッションにはIPアドレスやデバイスの情報は保存されません。サインインのセキュリティ記録は、IPアドレスとメールアドレスを含まない形で最大1時間保存されます。
  • サーバーの技術ログ（リクエストの日時、エラーの詳細。IPアドレスは含みません）は最大7日間保存され、自動的に削除されます。サーバーへの不正な接続の試みの送信元アドレス（ファイアウォールと管理アクセスのログ）も最大7日間保存されます。これらはゲームの通信ではありません。
  • アカウントを削除すると（プロフィール → 設定 → アカウント → アカウントを削除）、あなたのアカウントとそれに紐づくゲームデータは直ちに削除され、暗号化されたバックアップからも30日以内に消えます。例外：不正行為と返金を監査するため、ジェムの増減と不正行為のフラグは最大12か月、購入イベント（商品、日付、国、通貨、価格、トランザクションID）は最大24か月、あなたのアカウントとの紐づけを外したうえで保存され、その後削除または匿名化されます。RevenueCatには顧客記録の削除を依頼し、Appleでサインインしていた場合は、Appleに、このアプリに対する「Appleでサインイン」の認可の取り消しを依頼します。削除したこと自体は、日付とランダムなリクエスト番号だけで（あなたのIDは含めずに）3年間記録します。アカウントの削除を参照してください。
  • サポートメールは、リクエストの終了後、その対応内容を示すのに必要な期間だけ保存し、その後削除します。
  • ストアのレシートはあなたのApple Accountに、Game Centerの記録はAppleに残ります。
  • アプリを削除しても、削除されるのはあなたのデバイス上のデータだけです。サーバー上のゲストアカウントを削除するには、先にアプリの「アカウントを削除」を使うか、アプリに表示されるサポートコードを添えて私たちにメールしてください。

8. セキュリティ

データを保護するために、合理的な技術的・組織的対策を講じています。データは送信中にTLSで暗号化されます。バックアップはサーバー上で暗号化されます。データベースでは、各プレイヤーは自分のデータにしかアクセスできません（行レベルセキュリティ）。利用統計には外部から直接アクセスできません。残高や報酬などの重要な処理はサーバー上でのみ行われます。サーバーを管理するのは開発者だけです。あなたのデバイス上のデータは、デバイス自体のセキュリティによって保護されます。

完全に安全なシステムはなく、完全な安全性を保証することはできません。データ侵害を知った場合は、その影響を抑えるために対処し、法律が求める通知（必要に応じて管轄当局とあなたへの通知）を行います。

10. あなたの権利

GDPR（EEA・英国）と関連する現地法（スイス）、およびKVKK（トルコ）に基づき、あなたには自分のデータにアクセスしてそのコピーを受け取る権利、訂正する権利、消去する権利、処理の制限を求めるまたは処理に異議を述べる権利、ポータブルな形式で受け取る権利、同意を撤回する権利があります。

異議を述べる権利：正当な利益に基づく処理、特に利用統計に対しては、いつでも異議を述べることができます。いちばん簡単な方法は「プロフィール → 設定 → 利用統計」をオフにすることです。記録が止まり、過去の統計も削除されます。同意を与えていた場合も、同じ場所で撤回できます。パーソナライズ広告への許可は、iOSの「設定」→「プライバシーとセキュリティ」→「トラッキング」と、アプリのプライバシーの選択（プロフィール → 設定）で撤回できます。撤回しても、それ以前に行われた処理の適法性には影響しません。

リクエストの方法：「プロフィール → 設定 → アカウント → データをダウンロード」から、あなたのデータのコピーをすぐに受け取れます。アカウントの削除と表示名の変更もアプリ内でできます。そのほかのリクエストは、どの国にいても、destek@mm-apps.com宛てに直接メールを送り、アプリに表示されるサポートコード（プロフィール → 設定 → アカウント）を添えてください。このコードはあなたのデバイスにだけ表示され、リクエストがあなたからのものであることを私たちが確認するために使います。私たちは名前やメールアドレスを保存していないため、ほかの方法ではあなたのアカウントを見つけられない場合があります。30日以内に無料でお答えします。また、お住まいの地域のデータ保護機関、またはトルコでは個人データ保護委員会に苦情を申し立てることもできます。
