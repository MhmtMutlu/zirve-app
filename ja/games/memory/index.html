神経衰弱：カードの絵合わせゲーム

神経衰弱はおなじみのカードゲームです。カードを2枚めくり、そろえば開いたまま、そろわなければもう一度。登るほど盤面が大きくなり、まちがえたカードはより早く閉じ、30階からは3枚組を探します。

遊び方

カードをめくって、同じ絵を見つけよう。

  1. カードを2枚めくります。そろえば開いたまま、そろわなければすぐにまた閉じます。
  2. どこに何のカードがあるかを覚えて、すべてのペアを見つけよう。

上の階では

  • 12枚から24枚へ
  • 30階から：3枚組。同じ絵を3枚見つけよう
  • まちがえたカードはより早く閉じる

コツ

  • 最初の1周は、1行ずつ決まった順番でめくろう。そのほうが場所を思い出しやすくなります。
  • めくったカードが前に見たカードと同じ絵なら、すぐにそのペアを取ろう。
  • 登るほど、まちがえたカードは早く閉じます。めくりながら、絵と場所を心の中で唱えよう。
  • 3枚組では、開いた2枚の絵がちがうと、その回はすぐに終わります。自信のあるカードは2枚目にめくろう。

タワーのどこで登場するか

神経衰弱は、最初の階から遊べる4つのゲームのひとつです。その後はほかのゲームと混ざって登場し、登るほど難しくなります。

のんびりモードでは、解放したゲームをどれでも、時間制限なし・ライフ消費なしで遊べます。タワーは進みません。練習のためのモードです。

このタイプのパズルの呼び名

絵合わせやメモリーゲームとも呼ばれ、英語ではコンセントレーションとも呼ばれます。Zirveでは30階から、同じカード3枚で遊ぶバージョンが加わります。
